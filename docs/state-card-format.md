# 角色状态卡格式

状态卡用于把角色扮演里的关系数值从正文中分离出来，由应用渲染成可展开、收起的卡片。

## 1. 稳定标记

每轮 assistant 回复末尾输出一次：

```text
[[状态]]
闻灯｜女｜34｜无界驿站掌柜
好感度：42（+3）
欲望值：18
堕落度：6
备注：可选的一句话近况

周既明｜男｜38｜前港务调查员
仇恨值：73（-2）
信任值：21
戒备值：88
[[/状态]]
```

- 姓名行固定为 `姓名｜性别｜年龄｜身份`，角色必须成年。
- 女性角色使用 `好感度 / 欲望值 / 堕落度`。
- 男性角色使用 `仇恨值 / 信任值 / 戒备值`。
- 数值为 `0–100` 的整数；括号里的 `+3`、`-2` 是可选变化量。
- 同一角色每轮只出现一次，只列出本轮出场或被直接提及的角色。
- 状态卡不能写进角色气泡，正文也不重复数值。

解析器同时兼容 `【状态】...【/状态】`、`[状态]...[/状态]`、`好感:`、`欲望 18`、`仇恨度：73` 等常见变体。

## 2. 显示位置

`MessageItem` 在进入气泡或旁白解析前调用 `extractStateCard()`：

1. 从正文剥离完整状态块，或流式生成中的未闭合状态块。
2. 清理后的正文继续走普通对话、气泡和旁白渲染。
3. 解析出的数值渲染为 `StateCard`，放在消息正文之后、操作按钮之前。
4. 用户消息不解析状态卡。

复制消息、会话预览和向量记忆索引都会移除状态块，避免把数值协议写进故事正文或记忆片段。

## 3. 展开与收起

卡片默认折叠，只显示角色名和数值摘要；点击标题行后展开：

- 每位角色的年龄、身份；
- 各项数值的 0–100 进度条；
- 可选的变化量；
- 一句近况。

按钮使用 `aria-expanded`，数值使用 `role="progressbar"` 与 `aria-valuenow`。

## 4. 正则与 JavaScript 的边界

配套正则只负责把模型偶发写出的 `【状态】`、`[状态]`、`好感:`、`仇恨度` 等变体归一成稳定标记。

应用不会执行模型输出里的任意 JavaScript，也不会使用 `dangerouslySetInnerHTML`。真正的“JS 渲染卡片”由应用内受控的 React 组件完成，因此导入外部正则或角色卡不会获得浏览器脚本执行能力。
