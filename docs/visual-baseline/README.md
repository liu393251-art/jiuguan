## 使用方式

- 任务块的 `visual_baseline` 指向 `docs/design-guidelines.md` 与这里的截图。
- 构建/视觉校准只对齐既有风格、间距、字号、密度和组件状态，不重做信息架构。
- 审查 Agent 用同一组截图判断漂移；明显漂移记为 P1。
- 截图由 `tests/e2e/app.spec.ts` 的基线用例生成，统一使用 `pnpm test:e2e`，不手工启动 Vite。

## 规则

- 只放当前认可的版本，不放临时草稿。
- Light 为默认基线；Dark 至少用 E2E 验证可读性和无横向溢出。
- 截图尺寸、命名保持稳定；同一页面不要保留互相冲突的多套基线。
