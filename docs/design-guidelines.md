# 小白酒馆 · 视觉规范

本文件是小白酒馆 MVP 的视觉基线。新页面应继承这里的层级、节奏和组件状态，而不是重新发明一套主题。

## 1. 设计方向

关键词：**暖光书房、夜幕叙事、克制、近距离、可长时间阅读**。

产品不是工作台，也不是聊天工具后台。它更像一间只在夜里开门的酒馆：光线偏暖，信息层级清楚，留白足够，所有装饰都为“让人愿意继续说下去”服务。

避免：

- 赛博霓虹、荧光紫青、大面积高饱和渐变
- 传统 SillyTavern 的密集表单和无限嵌套面板
- 全屏玻璃拟态、重阴影叠重边框
- 把角色卡做成电商商品卡
- 聊天页出现工具栏竞赛

## 2. 色彩

所有颜色 token 只在 `src/styles/theme.css` 定义。

| Token                          | 用途                     |
| ------------------------------ | ------------------------ |
| `background`                   | 暖纸色页面底             |
| `foreground`                   | 深棕主文本               |
| `card`                         | 暖白内容表面             |
| `primary`                      | 铜/琥珀主操作、选中态    |
| `secondary` / `muted`          | 次级表面、输入背景       |
| `muted-foreground`             | 说明、时间、辅助信息     |
| `border`                       | 分隔和轻描边             |
| `chat-user` / `chat-assistant` | 两种消息气泡             |
| `glow`                         | 首页和角色页的暖光晕     |
| `destructive`                  | 删除与错误               |
| `success` / `warning` / `info` | 导入结果、连接状态、提示 |
| `sidebar*`                     | 深色书桌导航             |

规则：

- 禁止组件内写任意 hex。
- 新颜色先加语义 token，再使用 Tailwind 语义类。
- 主色用于行动和状态，不做大面积铺底。
- 深色不是简单反色：背景是深夜棕黑，卡片比背景略亮，主色提高明度但降低饱和。

## 3. 字体与排版

- 正文/UI：Manrope Variable + 中文无衬线回退（PingFang SC / 微软雅黑）。
- 标题/品牌：中文衬线回退（Songti SC / Noto Serif CJK SC），只用于页面标题、角色名、空态标题。
- 页面标题：32–40px，600，负字距。
- 角色详情名：36–44px。
- 区块标题：14–16px，600。
- 正文：14px，行高 1.68；聊天正文 13–22px 可调，默认 15px，行高 1.88。
- 辅助文字：10–12px。标签可加 0.18em 字距。

聊天正文是产品的第一阅读面。中文段落之间保留 0.8em 间距；引用使用左侧铜色细线；代码块使用 `muted` 底，不发光。

## 4. 布局

### 桌面端 1440

- 左侧固定 272px 深色导航：品牌、对话/配套/设置、角色库与导入区入口、真实 API 说明。
- 内容最大宽度 1180px，左右 32–40px。
- 对话列表为单列宽卡；角色库 2–3 列；设置和内容库使用 2 列卡片。
- 聊天页独立全屏，最大阅读宽度 896px（`max-w-4xl`），不显示主导航。

### 移动端 390

- 左上角固定汉堡按钮，打开左侧抽屉；抽屉上半部分为最近聊天与小加号新建，底部为设置和导入区，适配 safe-area。
- 页面顶部预留 56px，避免被移动端标题栏遮挡。
- 角色库单列；筛选标签横向滚动但不产生页面横向溢出。
- 聊天页全屏：顶部角色条 64px + 渲染状态条 + 消息区 + 底部输入。输入区适配键盘与 safe-area。
- 表格一律转卡片；不保留横向大表格。

## 5. 形状、边框与阴影

- 基础圆角 14.4px；卡片 16px；对话框 20–24px；消息气泡 16px，靠近说话者一侧上角收窄。
- 边框是一级层级工具；阴影只用于悬浮和对话框。
- 角色头像使用 `chart-1..5` 渐变 + 首字，不依赖远程图片。
- 首页/角色详情允许一处低对比暖光晕，其他地方保持平整。

## 6. 组件状态

所有交互组件必须覆盖：

- default / hover / focus-visible / active / disabled
- loading（提交、导入、流式、删除）
- error（表单、页面、逐项导入）
- empty（列表、筛选无结果、没有更早消息）

按钮规则：

- 主操作使用 `default`；次级使用 `outline`；导航/消息操作使用 `ghost`。
- 破坏性操作必须有确认对话框，并显示影响数量。
- 禁用态必须说明原因（如“没有更多”“还没有 API 连接”）。
- 图标按钮必须有 `aria-label`。

## 7. 聊天页

- 顶部：返回、头像、角色名 + 当前对话信息、字号 `- / +`、设置入口。
- 状态条：`安全文本渲染 · 最近 40 条分批加载 · 真实 API 请求/正在续写`。
- 消息：assistant 左侧带头像，user 右侧；最大宽度 78–86%。
- 多人回复按发言者拆分；`「」`、`“”` 或用户直接输入的正文显示为气泡并带发言者名与头像，用户靠右。动作、心理和环境作为无气泡叙述居中横跨聊天区，不挂头像，不另起“心理/环境”发言者；叙述字号略大于台词。用户用 `（）` 写的动作同样不渲染气泡，输入框上方提供 `“”` 与 `（）` 一键插入并在标点内定位光标。
- 流式：末尾铜色闪烁光标 + “正在续写”提示；输入框右侧变为停止按钮。
- 操作：复制、编辑（仅用户）、重试（最后一条 assistant）；桌面 hover 出现，移动端保持低透明度常驻。
- 滚动：用户接近底部时自动吸底；上翻后不抢滚动；显示“回到最新消息”。
- 长聊天：首屏 40 条；顶部“加载更早”；加载后保持视口位置。
- 禁止执行模型输出中的 HTML/脚本/iframe；渲染为受控 Markdown。

## 8. 导入区

- 导入区统一管理角色卡、预设、世界书和正则；右上角固定“导入文件”和“新建”。
- “新建”先选择内容类型，再进入对应编辑器。
- “导入文件”进入多文件识别页，识别完成后退回导入区。

- 顶部大拖拽区，虚线边框；拖入时主色描边 + 极浅主色底。
- 待导入文件为行卡：文件图标、文件名、大小、识别类型、摘要、目标库、类型下拉、跳过、状态。
- 成功用 `success` 轻底；失败用 `destructive` 轻底；跳过降低透明度。
- 多文件结果逐项展示，不能用一个全局 toast 替代。
- 未知类型必须明确写“无法识别”，不得猜测。

## 9. 动效

- 页面进入：透明度 + 6px 位移，180ms。
- 卡片 hover：位移不超过 2px，阴影轻微增加。
- 对话框：淡入 + 轻微缩放，200ms。
- 流式光标 1s 呼吸；不做持续发光。
- 尊重 `prefers-reduced-motion`，全局已降级。

## 10. 文案

- 具体、克制、有场景感，但不要过度文学化到影响操作。
- 空态说明下一步，例如“导入一张角色卡，或者手动写下第一个人物”。
- 错误说明发生了什么 + 可执行的下一步。
- API 能力必须诚实标注：“本地保存”“真实 API 请求”；密钥只保存在当前设备，并提示共享设备风险。
- 向量记忆必须明确标注“本机 IndexedDB 向量库 / 不上传云端数据库”；选择 API 时说明会调用 `/embeddings`，失败退回本机向量。
- 不用 TODO、Lorem、Click here、英文残留。

## 11. 可访问性

- 表单有可见 Label 和错误文本；对话框有 Title 与 Description。
- 颜色不是唯一状态表达；状态同时有文字或图标。
- 焦点环使用 `ring`，键盘可完成主要操作。
- 长按多选必须同时提供“多选删除”按钮，触屏和键盘都能进入选择态。
- 消息操作按钮有可读名称，复制/停止/重试不能只靠图标。

## 12. 视觉验收

至少检查：

- 1440 × 900 首页、角色库、聊天、对话设置
- 390 × 844 同一组页面
- Light / Dark
- 移动端无横向溢出
- 对话框不超过视口，可滚动
- 聊天输入区不被底部安全区遮住
- 长聊天加载更早不跳视口

参考截图保存在 `docs/visual-baseline/`。新增页面先选一个最接近的参考页继承，不重新造主题。

审查优先级：

- `P0`：核心功能不可用
- `P1`：明显视觉漂移、响应式错误、信息层级丢失
- `P2`：不影响风格一致性的细节优化

只有 P0/P1 阻塞发布。
