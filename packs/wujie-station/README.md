# 无界驿站 · 开放叙事配套

这是一套 ZIP 配套包。请在小白酒馆的「导入区 → 导入配套」中导入 `wujie-station-open-pack.zip`，角色、预设、三本世界书和状态卡正则会在一次操作里导入并绑定。

## 设计方式

- `总纲` 负责门、车票、账本和铜铃，不绑定某一套题材。
- `当前篇 · 雾港来信` 是默认题材模块，可以整体替换或停用。
- `人物簿` 中四人都是成年人：闻灯 34 岁、周既明 38 岁、林晚 29 岁、顾临 31 岁。
- 预设负责文风、成年边界、开放题材槽和状态卡协议。
- 正则只把 `【状态】`、`[状态]`、`好感:` 等常见写法归一成稳定标记；真正的卡片由应用内的安全 React 渲染器显示，不执行模型输出的任意 JavaScript。

## 换成另一套题材

1. 新建一卷“当前篇 · 你的题材”世界书，写地点、组织、冲突和线索。
2. 在配套或当前对话设置里停用 `当前篇 · 雾港来信`，换上新的当前篇。
3. 需要时改人物簿里的职业、旧案和关系，但保留年龄与成年边界。
4. 总纲、状态卡协议和正则不用动。

## 状态卡格式

```text
[[状态]]
闻灯｜女｜34｜无界驿站掌柜
好感度：42（+3）
欲望值：18
堕落度：6

周既明｜男｜38｜前港务调查员
仇恨值：73（-2）
信任值：21
戒备值：88
[[/状态]]
```

状态卡不是正文。应用会把它从故事气泡中剥离，并渲染成可展开、收起的状态卡片。
